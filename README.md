#### Project guidelines:
    Hi, this project analyzes IPL tournament dataset for different purposes.

    Each file is independent of others but, for dataset each file depends
        on data.py.Each file imports data from data.py.

    This project will download dataset and create path to import it automatically in
    data.py still, you can download dataset if you want to use it on your own.

    You can download data from here:
(https://www.kaggle.com/datasets/manasgarg/ipl)

**1. Import project, create and activate .venv inside project root directory.**
      
      To create .venv in your local machine project root directory run this in your terminal :
  ``` python3 -m venv .venv```

      To activate .venv file, run this command in terminal:
  ``` source .venv/bin/activate ```
  
**2. Then, run this command to install all dependencies :**</br>

  ``` pip install -r requirements.txt ```

**3. Now, you are good to run this project files either from terminal or run button from any IDE.**

    How to run python project files from terminal ?

  ``` python3 filename.py```

    Example : 
   ``` python3 q1_total_runs_scored_by_teams_in_all_seasons.py```
